# Lloyd Gill Résumé Website

This folder is ready for GitHub Pages. The website uses plain HTML and CSS, so no special software or GitHub Action is required.

## Before uploading

1. Open the `assets` folder.
2. Delete the temporary `professional-photo.jpg` image.
3. Copy your professional headshot into the `assets` folder.
4. Rename your picture exactly `professional-photo.jpg`.
5. If you want to use a newer résumé, replace `Lloyd_Gill_Resume.pdf` with your updated PDF and keep the same filename.

The website automatically crops the photograph into a circle. For the best result, use a square or vertical headshot with your face centered near the top half of the image.

File names are case-sensitive. `professional-photo.jpg` and `Professional-Photo.JPG` are different names on GitHub.

## Upload the website to GitHub

1. Sign in at https://github.com.
2. Select the **+** button in the upper-right corner.
3. Select **New repository**.
4. Enter `lloyd-gill-resume-website` as the repository name.
5. Select **Public** so employers can view the website.
6. Do not select **Add a README file**, **Add .gitignore**, or **Choose a license**.
7. Select **Create repository**.
8. On the new repository page, select **uploading an existing file**.
9. Open this project folder on your computer.
10. Drag `index.html`, `styles.css`, `README.md`, `.nojekyll`, and the entire `assets` folder into the GitHub upload area.
11. In the commit message box, enter `Add résumé website`.
12. Select **Commit changes**.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Select **Settings**.
3. Select **Pages** in the left menu.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Under **Branch**, choose `main` and `/ (root)`.
6. Select **Save**.
7. Wait two to five minutes and refresh the Pages settings screen.
8. GitHub will display the website link near the top of the page.

The address will normally be:

`https://YOUR-GITHUB-USERNAME.github.io/lloyd-gill-resume-website/`

Replace `YOUR-GITHUB-USERNAME` with your actual GitHub username.

## Update the website later

1. Open the repository on GitHub.
2. Select **Add file**, then **Upload files**.
3. Upload the changed file using the exact same filename.
4. Confirm **Replace** if GitHub asks.
5. Select **Commit changes**.

GitHub Pages will automatically publish the update. You do not need to select a GitHub Action for this website.
